Política de privacidad de Mr Stick Uploader

Última actualización: 28 de octubre de 2026

Mr Stick Uploader es una herramienta privada del canal de YouTube Mr. Stick (@Mr.Stick-Tv). Solo la usa el propietario del canal para gestionar su propio canal. No está disponible para el público.

Qué datos usa

Con la autorización del propietario del canal, a través de los Servicios de API de YouTube, la herramienta:

  • Sube los videos del propio canal y edita sus títulos, descripciones, miniaturas y subtítulos.
  • Lee las estadísticas del propio canal (vistas, retención, ingresos estimados) para mejorar los videos.
  • Lee los comentarios públicos de los videos del propio canal para conocer las opiniones de la audiencia.

No accede a datos de otras cuentas de Google ni a información personal de los espectadores más allá de lo que YouTube muestra públicamente.

Dónde se guardan

El permiso de acceso y las estadísticas se guardan únicamente en el ordenador del propietario del canal. No se venden, no se comparten con terceros y no se usan para publicidad.

Cómo retirar el acceso

El acceso puede revocarse en cualquier momento desde la página de permisos de Google: myaccount.google.com/permissions. También se puede consultar la configuración de seguridad de Google.

Servicios de terceros

Esta herramienta usa los Servicios de API de YouTube. Al usarla se aplican los Términos de Servicio de YouTube y la Política de Privacidad de Google.

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los Servicios de API de Google, incluidos los requisitos de uso limitado.

Privacy Policy (English)

Mr Stick Uploader is a private tool of the YouTube channel Mr. Stick (@Mr.Stick-Tv), used only by the channel owner to manage their own channel. It is not available to the public.

Data used: with the channel owner's authorization, through the YouTube API Services, the tool uploads the channel's own videos and edits their titles, descriptions, thumbnails and captions; reads the channel's own analytics (views, retention, estimated revenue); and reads public comments on the channel's own videos. It does not access other Google accounts or viewers' personal information beyond what YouTube shows publicly.

Storage: authorization tokens and analytics are stored only on the channel owner's computer. They are never sold, shared with third parties or used for advertising.

Revoking access: access can be revoked at any time at myaccount.google.com/permissions or via Google security settings.

Third parties: this tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service; see also the Google Privacy Policy. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
